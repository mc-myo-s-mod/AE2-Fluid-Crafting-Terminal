# AE2 유체 제작 터미널

AE2FCT는 기존 AE2 터미널에 가상 유체 제작 지원을 추가합니다. 가상 유체는 ME 유체를 양동이 단위의 제작 재료로 표현하므로, 지원되는 양동이 레시피는 격자에 양동이를 두지 않고 ME 저장소의 유체를 사용할 수 있습니다.
